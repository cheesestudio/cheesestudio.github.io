魅魔社 VIP 名单管理：朋友电脑使用教程

适用于 Windows 10 / 11、名单编辑器 v1.1。首次配置一次，以后打开软件就可以更新名单。不需要安装 Unity 或 Python。

一、先由仓库主人准备

1. 让朋友注册自己的 GitHub 账号，并把 GitHub 用户名发给你。
2. 打开仓库：https://github.com/cheesestudio/cheesestudio.github.io
3. 进入 Settings → Collaborators → Add people，搜索朋友的用户名并发送邀请。朋友接受邀请后，才有提交权限。GitHub 邀请协作者说明（https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository）
4. 把本教程和 MeiMoSheVIPManager-Windows-v1.1.zip 发给朋友。

朋友使用自己的账号登录，不需要你的密码或令牌。注意：这里授予的是仓库协作权限，覆盖整个仓库，并非只允许修改 TXT；软件自身的一键提交只更新名单。GitHub 权限说明（https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository）

---

以下内容由朋友操作。

二、安装两个工具

先接受 GitHub 邮件或网页通知里的仓库邀请，然后安装：

- Git for Windows：https://git-scm.com/install/windows
- GitHub CLI：https://cli.github.com/

安装完成后，重新打开一个 PowerShell 窗口，分别执行：

git --version
gh --version

两条命令都能显示版本号，再继续。提示找不到命令时，先关闭 PowerShell 重新打开；仍不行，再检查是否安装成功。

三、登录自己的 GitHub 账号

在 PowerShell 中执行：

gh auth login --hostname github.com --git-protocol https --web

按提示复制一次性验证码，打开浏览器完成授权。浏览器里登录的必须是接受了仓库邀请的那个账号。授权成功后再执行：

gh auth setup-git --hostname github.com
gh auth status --hostname github.com

第一条命令让本机 Git 使用 GitHub CLI 的登录凭据；第二条检查当前登录状态。以后软件会使用这个登录状态提交。登录说明（https://cli.github.com/manual/gh_auth_login） · Git 凭据配置说明（https://cli.github.com/manual/gh_auth_setup-git）

如果这里出现连接超时，先按文末“无法连接 GitHub”处理，再继续。

四、把名单仓库克隆到自己的电脑

在 PowerShell 中执行：

git clone --branch main --single-branch --depth 1 https://github.com/cheesestudio/cheesestudio.github.io.git "$env:USERPROFILE\SuccubusVIP"

这会在当前 Windows 用户目录下创建 SuccubusVIP 文件夹。例如：

C:\Users\你的Windows用户名\SuccubusVIP

确认克隆成功后，再执行：

Set-Location "$env:USERPROFILE\SuccubusVIP"
git remote get-url origin

显示的地址应为：

https://github.com/cheesestudio/cheesestudio.github.io.git

这里需要的是 git clone 得到的仓库，里面有隐藏的 .git 目录。只下载网页上的 ZIP、只复制 TXT，或克隆自己的 Fork，都会导致软件不能直接更新这份名单。

如果提示 SuccubusVIP 文件夹已经存在，不要覆盖或删除里面的文件。若之前已经完成克隆，直接进入原文件夹；否则找仓库主人确认后换一个空目录克隆。

五、设置提交署名

仍然在刚才的 SuccubusVIP 文件夹内，分别执行下面两条命令。把引号内文字换成自己的信息：

git config user.name "你的GitHub用户名"
git config user.email "你的GitHub提交邮箱"

邮箱可以使用 GitHub Settings → Emails 中显示的 noreply 隐私邮箱，直接完整复制那个地址。这里设置的是提交署名，不是登录密码，并且只影响当前仓库。GitHub 提交邮箱说明（https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address）

六、把软件放进仓库文件夹

1. 将收到的 MeiMoSheVIPManager-Windows-v1.1.zip 完整解压。
2. 打开解压后的 MeiMoSheVIPManager 文件夹。
3. 把其中的 MeiMoSheVIPManager.exe 和整个 _internal 文件夹，一起复制到刚才克隆出来的 SuccubusVIP 文件夹。

最终应是这样的结构：

SuccubusVIP\
├─ .git\                       ← 隐藏目录，不要删除
├─ SuccubusList.txt             ← 名单
├─ MeiMoSheVIPManager.exe       ← 双击它启动
├─ _internal\                  ← 软件依赖，必须与 EXE 一起保留
├─ SuccubusVIPArt\
└─ ……其他仓库文件

EXE 要和 SuccubusList.txt 在同一层，不要只把整个软件文件夹套进去。 这样软件首次启动就会自动找到你电脑上的名单，不会使用作者电脑的 D:\Code\Git\... 路径。

双击 MeiMoSheVIPManager.exe。这里使用的是免 Python 版本，不用点仓库里的 StartSuccubusVIP.cmd。

如果软件顶部仍显示了别的路径，等待当前操作结束，点击“选择名单文件”，选择你刚才克隆的 SuccubusVIP\SuccubusList.txt，软件会记住它。

七、以后每次更新名单

1. 打开软件，点击 “读取 GitHub”，先载入最新名单。
2. 新增玩家：输入 VRChat 的显示昵称，选择徽章类别，再点击 “新增 / 更新所选玩家”。
3. 修改玩家：先点击表格里那一行，再修改昵称或类别，然后点击 “新增 / 更新所选玩家”。
4. 删除玩家：选中对应行，点击 “删除所选玩家”。
5. 检查表格正确后，点击右上角 “一键保存并提交 GitHub”。
6. 等到底部出现 “已发布到 GitHub · 提交……”，才表示发布成功。

只在输入框里打字还不够，必须先点击“新增 / 更新所选玩家”，让修改进入表格。“仅保存本地 TXT”不会上传到 GitHub。

昵称按游戏内显示内容填写，保留大小写、空格和特殊符号。例如 Cheese ≻v≺，不要填 usr_... 账号 ID。

| 类别 | 徽章 |
|---|---|
| 1 | 粉樱初契 |
| 2 | 月魅银辉 |
| 3 | 绯红誓约 |
| 4 | 鎏金契约 |
| 5 | 幻晶星冕 |
| 6 | 永夜魔冠 |

Cheese ≻v≺ 和 艾拉贝尔ElaBlade 当前指定使用类别 6。

软件会自动生成更新版本号。不要手动改 revision，也不要为了删除全部玩家把 TXT 清成空文件；在软件里删除后提交即可。

八、两个人一起管理时怎么避免覆盖

每次准备编辑前，先点“读取 GitHub”。如果软件提示 “GitHub 名单已被其他人修改”，说明你编辑期间另一位管理员已经提交了：

1. 先记下你本次要新增、修改、删除的玩家及类别，必要时截图。
2. 点击“读取 GitHub”，确认载入最新名单。这个操作会替换当前表格内容，所以先记下自己的改动。
3. 在最新名单上重新做自己的修改，再提交。

不需要强推，不需要在命令行输入 git push --force。日常只用软件的读取、编辑、提交即可，也不需要额外执行 git pull 或 git commit。

软件发布时保留本地 Git 分支，因此 Git 工具有时仍显示本地 TXT 有修改；先看软件发布结果和 GitHub 页面，不要因此反复提交或重置仓库。

九、常见问题

无法连接 GitHub / 443 端口超时

先确认自己的电脑能正常访问 GitHub。若平时使用代理访问，请启动你自己电脑上的代理软件并开启系统代理。v1.1 编辑器会读取 Windows 已启用的系统代理。

代理地址必须是你自己的。作者使用的 127.0.0.1:7890 不一定适用于你的电脑。

如果 PowerShell 里的登录或克隆命令仍然连不上，可以在代理软件里复制本地 HTTP 代理地址，然后在同一个 PowerShell 窗口执行：

$env:HTTPS_PROXY = Read-Host "粘贴你自己的HTTP代理地址，例如 http://127.0.0.1:7890"
$env:HTTP_PROXY = $env:HTTPS_PROXY

随后重试刚才失败的登录或克隆命令。这两行只影响当前 PowerShell 及其启动的程序，关闭窗口后失效，不会修改 Git 全局代理设置。

如果软件提交失败，本地保存的修改仍保留着。恢复连接后可以重试；如果期间另一位管理员已更新名单，则按上一节合并自己的修改。

403 / Permission denied / 没有写入权限

确认已经接受仓库邀请，并且登录的是被邀请的账号。在 PowerShell 执行 gh auth status --hostname github.com 检查账号；账号不对时，重新执行第三节的登录步骤。只在浏览器里登录 GitHub，不等于本机 Git 已配置好登录凭据。

Please tell me who you are / unable to auto-detect email address

这是没有设置提交署名。进入 SuccubusVIP 文件夹，补做第五节的 git config user.name 和 git config user.email。

not a git repository / origin 与配置的名单仓库不同

检查选中的 TXT 是否来自第四节用 git clone 得到的目录；不要选 QQ 下载目录里的单独 TXT，也不要选自己的 Fork。原仓库地址必须与第四节显示的一致。

提示 TXT 被其他程序修改

暂时不要继续保存，先记下本次改动。检查是否同时开着两个编辑器，或用记事本修改过名单，再重新读取正确版本。软件拦截覆盖是为了保留另一个程序的修改。

提交成功了，游戏里还没有变化

可以先到 GitHub 的 main 分支查看 SuccubusList.txt，确认名单已更新。测试地图会在玩家进入、定时刷新或点击 Refresh roster 时尝试下载；缓存和下载队列可能造成延迟。需要房间中至少一人能下载名单，当前原始文件地址还要求下载者开启世界的 Allow Untrusted URLs。

以上行为针对已经安装这套 VIP 系统的地图版本；没有安装系统的旧地图不会因为名单更新而自动获得功能。

怎么更新软件本身

关闭旧窗口，收到新版压缩包后完整解压，再替换仓库目录里的 EXE 和 _internal 文件夹。保留 .git、SuccubusList.txt 和其他仓库文件。不要把自己的账号凭据或软件设置目录发给别人。

首次配置完成后，日常操作就是：打开软件 → 读取 GitHub → 修改表格 → 一键保存并提交 GitHub。
